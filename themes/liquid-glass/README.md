# ThemePark — Liquid Glass (browser theme pack)

Manifest-only Chrome theme that styles the **browser chrome** (tabs, toolbar,
omnibox, bookmarks bar, new-tab page) to match the extension's glass mode.

## Why a separate package

Per AGENTS.md platform truth: browser UI cannot be scripted by extensions.
The only sanctioned mechanism is a theme manifest — no JS allowed, so the
pack is static. The extension cannot install or switch themes
programmatically; the user loads this pack once.

## Colors

Same palette as the extension's glass mode: a macOS Sonoma-style gradient
(deep blue `#22456e` → indigo → violet → rose `#9a5b80`) rendered as **real
PNG images** — `theme_ntp_background` (new-tab wallpaper) and `theme_frame`
(top strip, with a dimmed inactive variant). Chrome colors match the
gradient's top band so frame and wallpaper blend seamlessly.

**Alpha policy, proven from Chromium source** (`browser_theme_pack.cc`):
- `omnibox_background` / `button_background` carry alpha (frosted where the
  browser supports it).
- `frame`, `frame_inactive`, `frame_incognito*`, `background_tab*` and
  `toolbar` are **hardcoded opaque** by Chromium (`kOpaqueColors`) — no theme
  from anyone can make the toolbar translucent over the page. Our values are
  gradient-matched solids instead of pretending otherwise.

## Assets

`assets/*.png` are generated by `scripts/gen-theme-assets.mjs` (dependency-
free PNG encoder, deterministic output). Re-run only when changing the
gradient design; outputs are committed so packaging never needs Node.

## Install

`chrome://extensions` → Developer mode → **Load unpacked** → select this
folder. (Or via the zipped release asset once published.)

## Icons

Toolbar icons are **tinted** (`tints.buttons`), not replaced — no API exists
to swap browser icon artwork. That is a platform limit, documented here and
in the store listing, not a TODO.
